# 双语台词搜索

一个基于字幕时间轴的中英文台词搜索与片段播放工具。支持集数筛选、分批加载、双语同步字幕和可恢复选中台词的链接。使用原生 JavaScript 和 Node.js，无运行时第三方依赖。

**克隆仓库后显示的是原创演示数据。** 本机导入的剧集字幕与视频保存在 Git 忽略的文件中，不随代码发布。演示数据没有视频，因此只能体验搜索和分享链接，不能验证片段播放。

## 启动

需要 Node.js 20 或更高版本。在项目目录运行 `npm start`，打开终端显示的 `http://localhost:4173`。运行 `npm test` 检查数据解析与搜索。

无需安装 npm 依赖。服务器只在本机监听，提供静态页面和可选的本地视频文件。克隆后直接运行即可使用演示数据。

GitHub Actions 会在每次推送和拉取请求时运行 `npm test`。

## 导入真实素材

1. 在项目目录的上级新建 `need/`，将你有权使用的中英文 SRT 放入，按 `Example S01E03.srt` 和 `Example S01E03-EN.srt` 命名，运行：

   `npm run import`

   脚本会自动识别 `S01E03` 这样的集数，更新该集台词并保留其他集。重复运行只替换同一集，不会生成重复结果。也可明确指定一集：`node scripts/import-srt.js "中文.srt" "English.srt" S01E03`。每集需要恰好一份中文 SRT 和一份文件名以 `-EN.srt` 结尾的英文字幕；若某集尚未准备齐全，请暂时不要将单个字幕放进 `need/`。中英文按时间重叠配对，导入后仍需抽查。导入结果写入本地 `data/dialogues.json` 和 `data/episodes.json`，两者均不会进入 Git。

2. 把浏览器可播放的 `S01E03.mp4` 放在本项目 `media/` 下。导入脚本会自动登记视频路径；若缺少 MP4，会明确提示，字幕仍可搜索。`media/` 及各类视频、字幕文件均被 Git 忽略。
3. 刷新页面。搜索中英文关键词，点结果播放。地址中的 `line` 参数可恢复选中的台词。

视频和字幕应当是同一剪辑版本。若原片是 MKV 且浏览器不支持，请用媒体转换工具转成 MP4（H.264 视频、AAC 音频）。如果已有 FFmpeg，可以使用 `ffmpeg -i input.mkv -map 0:v:0 -map 0:a:0 -c:v copy -c:a aac -b:a 192k -ac 2 -movflags +faststart media/S01E03.mp4`。只使用你有权使用和分发的素材。

开发者本机的 `need/` 现有四集素材，导入后共 1602 条台词；这些素材与生成数据不随仓库发布。中文版字幕原本逐条附带英文，导入时仅保留中文行。S01E17 有两条台词未在独立英文字幕中找到重叠时间段：`S01E17-0347`、`S01E17-0389`，界面保留中文、英文留空。

## 验收

- 在新克隆中输入 `time` 或“时间”可看到演示记录；导入真实数据后可输入 `peanut` 或“花生”。输入不存在的词会看到空结果提示。
- 在“筛选集数”中选定某一集，结果只显示该集台词；切回“全部集数”恢复跨集搜索。结果初次显示 40 条，点击“再显示”逐批增加。
- 点击台词后，播放器根据该行时间定位，前后各保留两秒，时间到后暂停；如果媒体缺失，页面显示提示。
- 播放时字幕区域根据当前时间显示中文和英文。
- 复制分享链接并在新标签页打开，恢复该条台词。自动播放可能受浏览器限制，此时点播放即可。
- 把浏览器窗口缩窄至手机宽度，搜索、卡片、播放器应保持可用。

## 发布到 GitHub

本仓库只发布代码、文档和原创演示数据。提交前运行 `git status --short` 或 `git ls-files`，确认没有 `media/`、`need/`、SRT、MKV、MP4、`data/dialogues.json`、`data/episodes.json`、`.env` 或 `node_modules/`。普通 GitHub 仓库也不适合存放大视频。

上传代码仓库并不会自动发布可供他人观看的剧集视频。目前分享链接指向本机 `localhost`；如要提供公开网站，需要另外部署前端、设置可公开访问且有分发许可的视频地址，并检查分享链接的公网域名。尚未为本项目选择开源许可证；若希望他人复用代码，可在发布前确定许可证。
